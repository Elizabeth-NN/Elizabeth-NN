## Featured Project

### [Video Explainer Agent](https://github.com/Elizabeth-NN/video-explainer-agent)

An AI-powered educational video generation platform focused on computer science and physics.

- Automated research and content generation.
- AI-assisted scriptwriting and content refinement.
- LangGraph workflows for orchestrating generation steps.
- Text-to-speech narration.
- Animated educational visuals and video rendering with Remotion and Manim.
- A web dashboard backed by a Python API.
